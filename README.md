# Каталог брендов

Глобальный каталог брендов, с которыми можно построить бизнес: франшиза, дистрибуция,
лицензирование, дилерство и другие модели сотрудничества.

На главной — база брендов. Внутри карточки — условия, вложения, доступные страны,
контакты и источники.

**Сайт:** https://omarmardanov.github.io/brands/

## Разработка

```sh
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
```

Посмотреть с телефона в той же сети:

```sh
npm run build && npx astro preview --host 0.0.0.0
```

## Устройство

- **Astro** — статический генератор. Каждый бренд и каждый фильтр получают настоящий
  URL, поэтому страницы индексируются.
- **Данные** — `src/data/brands/*.json`. Схема описана в `src/content.config.ts` и
  проверяется на сборке: некорректные данные роняют билд.
- **Стили** — дизайн-система [Intuition Design System](https://github.com/intuition-tech/ids),
  скопирована в `public/ids/` (MIT, лицензия рядом). Своего кода — только `public/site.css`.

## Данные

Собраны из открытых источников. В каждой карточке указаны ссылка на источник и дата
проверки. Публикуются факты — суммы, роялти, страны, сроки; описания написаны заново.
Контакты только корпоративные.

Нашли неточность или хотите добавить бренд — заводите issue.
